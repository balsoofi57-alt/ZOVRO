# ZOVRO Final UI Design Lock

**Status:** APPROVED / LOCKED  
**Approved:** 2026-09-26

## Locked visual direction
- Metallic silver is the dominant visual material.
- Midnight navy is the primary dark structural color.
- Gold is reserved for primary calls to action and premium highlights.
- Blue is reserved for GPS/location emphasis and selected navigation/location accents.
- Customer-facing application UI remains English-only.
- ZOVRO official branding and logo remain consistent across the app and website.
- Main experience follows the approved premium mobile mockup: service-first home, compact service grid, provider discovery, location confirmation/tracking, chat, completion/rating, and profile.

## Functionality protection
This lock is **visual only**. Existing application capabilities must remain intact, including:
- authentication and account recovery
- customer/provider roles
- service requests and dispatch
- GPS/location detection and sharing
- nearby provider discovery
- live tracking
- job chat
- provider availability
- notifications
- payments and payout flows where enabled by release gates
- ratings/reviews
- support and legal flows
- security and verification behavior

Do not remove, disable, or rewrite these functions merely to match a visual mockup.

## Change control
Do not replace this approved design, restore an older design, or materially change the color system/layout without explicit owner approval.
