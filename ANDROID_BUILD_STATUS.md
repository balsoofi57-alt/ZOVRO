# ZOVRO Android Release Candidate

Automated Android build branch: `android-release`.

- App ID: `com.zovro.app`
- Languages: English and Spanish
- Production API: `https://zovro-api.onrender.com`
- Build outputs: debug APK and unsigned release AAB
- Final Play Store upload requires the private upload signing key and Google Play Console access.

This branch is isolated from the live production website so Android build work cannot interrupt the deployed ZOVRO web app.
